# 施法生成逻辑规划

## 目标

本项目把法术视为可执行流程，而不是百科条目。

用户把节点放入施法阶段，系统根据规则判断链路是否成立。成立后前端展示法术名称、简述、阶段结果和六维雷达；失败或高危信息保留在 API 返回中，供后续细化展示。

核心判断：

```text
魔法是理解框架。
法术是可执行流程的结果。
```

## 当前 MVP 逻辑

MVP 只支持普通法术四阶段：

```text
开模 → 提纯 → 灌注 → 释放
```

阶段内部是有序节点列表。前端显示为四列流程，后端按固定顺序编译。

### 开模

生成模具或作用形态。

当前节点：

```text
球形、刃形、范围、线形、墙体
```

### 提纯

生成元素或复合属性。

当前节点：

```text
火、水、风、土、以太操作
```

当前复合规则：

```text
火 + 风 + 水 → 雷电系法术
土 + 水 → 泥沼系法术
水 + 土 → 泥沼系法术
```

### 灌注

把提纯结果注入开模结构。

当前节点：

```text
标准灌注、压缩灌注、范围灌注、多重灌注
```

硬规则：

- 必须已有开模结果。
- 必须已有提纯结果。
- 缺少任意输入都会失败。

### 释放

让已完成的灌注结构生效。

当前节点：

```text
投射释放、激发释放、扩散释放、流动释放、场域释放
```

硬规则：

- 必须已有灌注结果。
- 高危释放可形成结果，但会进入 `unsafe`。

## 数据结构

运行时数据：

```text
data/nodes/mvp_nodes.json
data/texts/zh_cn.json
data/examples/*.json
```

人工参考资料：

```text
data/magic_have/*.md
```

节点定义包含：

```text
id
stage
name
category
selection_class
name_role
stack_key
exclusive_group
name_affix
buff_label
summary
outputs
tags
risk_tags
score_bias
```

节点分类：

```text
core    核心节点，同阶段单选，决定基础法术大类。
detail  变形节点，可多选但同种最多一次，可通过 exclusive_group 互斥。
tuning  调节节点，可重复叠加，通过 stack_key 合并显示次数。
```

节点实例包含：

```text
node_id
instance_id
```

`node_id` 指向节点库定义，`instance_id` 指向画布上的一次使用。

## 编译流程

1. 读取节点库。
2. 校验四阶段是否完整、唯一、非空。
3. 校验节点存在且阶段正确。
4. 编译开模输出。
5. 编译提纯输出，必要时匹配表内复合。
6. 编译灌注输出，消费开模和提纯结果。
7. 编译释放输出，消费灌注结果。
8. 聚合风险标签和评分偏置。
9. 生成状态、法术名、简述、阶段结果、问题列表、摘要数据和六维雷达。

## 中文文本来源

```text
data/texts/zh_cn.json
```

该文件集中维护：

- 前端 UI 文案。
- 节点分类标题与阶段说明。
- 编译器阶段标签、雷达标签和风险文本。
- 60 个固定法术的显示名称与简介。

节点本体名称、节点标签、数值和叠加规则仍在 `data/nodes/mvp_nodes.json`。固定法术的基础签名仍在 `backend/app/fixed_spell_profiles.py`。

## 输出状态

```text
compiled  链路成立且无高危阻断。
partial   预留状态，后续用于部分成立或需补全的链路。
failed    硬规则失败，不能形成可执行法术。
unsafe    链路可形成，但风险足以要求高危标记。
```

## 问题数据

API 中每个问题必须尽量定位到阶段和节点实例。当前精简前端不展开问题列表，只用状态提示合法、失败或高危。

```text
rule_id
severity
stage
node_instance_id
message
suggestion
```

## 六维雷达

```text
威力
稳定性
学习难度
魔力消耗
泛用性
学术价值
```

安全性不再作为雷达维度。高危结果由 `unsafe` 状态和风险标签判断。

## 当前示例

```text
火球术：球形 → 火 → 标准灌注 → 投射释放
多重风刃：刃形 → 风 → 多重灌注 → 流动释放
泥沼术：范围 → 土 + 水 → 范围灌注 → 扩散释放
雷电术：线形 → 火 + 风 + 水 → 压缩灌注 → 激发释放
```

雷电术应返回 `unsafe`，因为链路可形成但风险高。
