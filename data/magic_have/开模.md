# 开模

整理范围：火、水、土、风、以太无属性、以太操作系字幕中明确出现或可直接归入“成型/维持”的手法。

## 核心作用

开模负责先把法术定成可维持、可承载后续提纯或灌注的形态。重点不是威力，而是形状、结构、维持方式和用途。

## 通用手法

| 手法 | 做法 | 适用方向 |
| --- | --- | --- |
| 点状/团状成型 | 在需要的位置生成一小团元素或混合物 | 火苗、水滴、无属性团块 |
| 弹体成型 | 生成球、石块、混合物团等可投射形态 | 火球、石弹、魔弹 |
| 线/束成型 | 生成一束气流、水流或矢量 | 吹风术、水流术、动能术 |
| 环形模具 | 生成并维持环状火圈 | 阻挡靠近、防御 |
| 墙体模具 | 生成并维持墙、屏障、液体墙壁 | 防御、卸力、抗属性 |
| 囚牢模具 | 生成并维持由水或土石构成的封闭结构 | 限制行动、控制呼吸、困住目标 |
| 范围模具 | 在目标脚下、目标周围或指定范围建立法术作用区 | 沼泽、暴风、力场 |
| 矢量模具 | 生成并维持数道矢量，以持续施力形成感知或控制框架 | 法师之眼、力场术 |

## 各体系开模形态

| 体系 | 开模形状/结构 | 维持重点 | 典型用途 |
| --- | --- | --- | --- |
| 火系 | 小火苗、火球、环状火圈、一团火焰 | 火焰形态稳定，避免过早扩散 | 引燃、灼烧、抵御靠近、后续扩散 |
| 水系 | 水滴、一汪水、水流、水牢、液体墙壁 | 水流不断运动且保持封闭结构 | 灭火、降温、限制、卸力、防御 |
| 土系 | 灰尘、石块、土墙、囚牢、指定外形与硬度的土石结构 | 结构分布合理，减少维持成本 | 砸击、防御、困锁、地形改造 |
| 风系 | 微风、气流、持续运动气流、漩涡气流、风屏障 | 压住不稳定的风元素，防止散掉 | 干扰、切割、加速、攻防屏障 |
| 以太无属性 | 无属性混合物团、无属性屏障、沼泽区域、无属性方块 | 调整元素比例与性质变化 | 限制、削减攻击、侵蚀、转化法术 |
| 以太操作系 | 挪移点、动能矢量、数道感知矢量、目标周围持续力场 | 精确维持矢量方向与作用对象 | 移动物体、探知行动、干扰、反弹 |

## 字幕中的代表例

- 火环术：生成并维持环状火圈，用热量阻止目标主动靠近。
- 水牢术：生成并维持水构成的囚牢，用水流控制行动甚至呼吸。
- 土墙术：生成并维持土墙，以硬度直接抵御攻击。
- 魔障壁：生成并维持无属性屏障，通过性质不断变化削减攻击。
- 法师之眼：生成并维持数道矢量，用持续动能施加探知目标行动。
- 御风术：把现有的风挤压并束缚至一处，维持成攻防一体的屏障。
