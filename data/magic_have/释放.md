# 释放

整理范围：字幕中明确提到“释放”的法术，以及投射、激发、扩散、反弹、操控等出手方式。

## 核心作用

释放负责决定法术怎样离开模具、怎样作用到目标，以及命中后继续怎样变化。字幕里多次强调，释放手段直接影响性价比和最终效果。

## 通用手法

| 手法 | 做法 | 结果 |
| --- | --- | --- |
| 投射释放 | 把成型物甩出、喷出、打出或投掷出去 | 基础命中、引燃、打湿、砸击、冲击 |
| 激发释放 | 在合适时机把压缩内容从模具中激发 | 子弹式爆发、点状穿透 |
| 扩散释放 | 命中或出手后持续延伸、分化、覆盖范围 | 大范围吞没、焚烧 |
| 流动释放 | 让水流、气流持续运动 | 卸力、切割、推动、限制 |
| 渗透释放 | 接触目标后沿缝隙侵入 | 体内浸没、内部破坏、医疗应用 |
| 结构释放 | 在指定位置生成合适外形与硬度 | 防御、限制、地形改变、二次变形 |
| 反制释放 | 观察对方施法后用对应性质消解或借力增强 | 克制攻击、复制并改良效果 |
| 力场释放 | 在目标周围制造持续力场 | 转向、接近、反弹、不合理受力 |
| 精确操控释放 | 直接操纵现有元素或力 | 御火、御水、御土、御风、御力 |

## 各体系释放手法

| 体系 | 释放方式 | 代表效果 |
| --- | --- | --- |
| 火系 | 火球打出、火弹激发、火花延伸分化、超大范围覆盖 | 灼烧、扩散、焚烧殆尽、由内而外燃烧 |
| 水系 | 水流喷出、压缩水流激发、接触后渗透、波浪冲击 | 灭火降温、洞穿直线、体内浸没、动能碾压 |
| 土系 | 石块投掷、指定结构生成、二次改变外形与硬度、地貌改造 | 直接砸击、防御、困锁、地震、改变地形 |
| 风系 | 气流推出、风刃切割、乱流覆盖、气流推力加速、龙卷自运作 | 干扰、斩击、飞行、持续漩涡 |
| 以太无属性 | 混合物甩出、沼泽侵蚀、模仿反制、无属性方块转化接触法术 | 限制、腐蚀、消解攻击、强化自身 |
| 以太操作系 | 动能冲击、多矢量扰乱、力场转向/反弹、矢量引导 | 打断步骤、操控目标、改变力流向 |

## 字幕中的代表例

- 火花术：制造一团火焰，击打出去后不断延伸、分化，再延伸再分化，直到吞没目标范围。
- 焚烧术：通过火焰超大范围释放，把法术效果覆盖到需要的每一处。
- 水刃术：把水流极致压缩后激发出去，洞穿直线范围内的一切。
- 水系渗透：水流接触目标后侵入体内，把内部完全浸没。
- 构造术：在适当场合生成适当外形与硬度，还能二次改变既有土石。
- 极星/气流加速类手法：制造气流施加到目标范围，让目标随推力不断加速，甚至飞起。
- 魔仿术：观察对方施法，用无属性中克制对方的元素消解攻击，并借助有利元素增强自身法术。
- 力场术：在目标周围制造持续性力场，让作用于目标的力朝不合常理的方向移动，达成转向、接近或反弹。
